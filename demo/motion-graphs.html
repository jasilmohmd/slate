ഇനി sliders നീക്കൂ. രണ്ട് graphs-ഉം ഒരേ motion അനുസരിച്ച് ഉടൻ മാറും. Position graph-ന്റെ slope-ഉം velocity graph-ന്റെ height-ഉം താരതമ്യം ചെയ്യൂ.

ചെയ്യേണ്ടത് / പ്രധാന ആശയം

Sliders ഉപയോഗിച്ച് initial velocity, acceleration എന്നിവ മാറ്റൂ. മുകളിലെ position–time graph മാത്രം നോക്കി അവസാന നിമിഷത്തിലെ velocity-യുടെ sign പ്രവചിച്ച് ഉറപ്പിക്കൂ.

Result കണ്ടശേഷം ഒരേ സമയത്ത് position graph-ന്റെ slope എങ്ങനെയാണെന്നും velocity graph-ന്റെ vertical value എത്രയാണെന്നും താരതമ്യം ചെയ്യൂ.

പ്രധാന ബന്ധം: Position–time graph-ന്റെ slope ആണ് velocity. Graph ഉയരത്തിലാണോ താഴെയാണോ എന്നത് മാത്രം നോക്കരുത്; ആ സമയത്ത് line ഏത് ദിശയിലേക്ക് ചരിയുന്നു എന്നതാണ് പ്രധാനപ്പെട്ടത്.

velocity = position–time graph-ന്റെ slope = Δs/Δt

Position graph മുകളിലേക്ക് ചരിയുമ്പോൾ velocity positive. Horizontal tangent ആകുമ്പോൾ velocity zero. താഴേക്ക് ചരിയുമ്പോൾ velocity negative.

Velocity–time graph-ൽ line-ന്റെ height തന്നെയാണ് velocity. അതിന്റെ slope acceleration ആണ്.

acceleration = velocity–time graph-ന്റെ slope = Δv/Δt

ഇവിടെ “distance–time graph” എന്ന് classroom-ൽ പറയാറുണ്ടെങ്കിലും, negative direction-ഉം തിരിഞ്ഞുള്ള motion-ഉം കാണിക്കാൻ ഉപയോഗിക്കുന്നത് കൃത്യമായി position–time graph ആണ്. Distance ഒരിക്കലും കുറയില്ല; position കുറയാം.

Model constant acceleration ആണ്. Air resistance, road friction തുടങ്ങിയവ ഇവിടെ ഉൾപ്പെടുത്തിയിട്ടില്ല.
